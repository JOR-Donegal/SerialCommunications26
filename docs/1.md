# Fundamentals

Long, long ago, we had to come up with ways of data signalling. One of the first ideas was that of _Morse code_, a series of binary digits (dot and dash) which encoded letters and numbers. The unit of time duration for the message was based on the length of a dot.

- A dash has the same time duration as three dots
- Each dot or dash is separated by a time duration equal to one dot
- Individual letters were spaced with a time duration of three dots
- Words were spaced with a time duration of seven dots 

There is no timing signal from side to side, the operator listens to the timing and gets it by ear. We call a link like this _asynchronous_. 

Generally, the length of symbols was chosen based on letter frequency; the likelihood of being used in English. For example, the most common letter in the language (E) is a single dot, less common letters use up to four dot/dash combinations. They almost got it right, most analysts figure Morse code is about 90% efficient.
