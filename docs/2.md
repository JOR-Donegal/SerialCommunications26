# ASCII Encoding

In modern serial communications, we are more likely to use 8-bit ASCII coding. 
Although 7-bit ASCII exists, nothing has used it for a generation or more. 
8-bit ASCII provides Latin characters, upper and lower case, numbers and many symbols.
