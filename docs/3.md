# RS232
With RS232, we can convert ASCII to an asynchronous signal.

To transmit the 8 bits of serial data, we need to know if the equipment is expecting the _most significant bit_ (MSB) or _least significant bit_ (LSB) first. For most of the protocols we will work with, its LSB first.

The letter A is 65 in base 10, 41 in base 16, or 0100 0001 in binary. 

The waveform is discernible, but we could struggle to count the zeros in the middle. In real asynchronous communications, the letters arrive at random intervals, somehow, we need to know when a message starts.

The most basic serial protocol we use is RS232. When there is no signal, the line is high or “1”. 

To signal the start of a character, a _start bit_ of zero is inserted. If we know the speed of link, we know how much time should elapse from the start of the start bit to the middle of the next bit. At 9,600 bit/second the time between bits is 1.042 x 10^-4^ seconds. This tells us when to sample each bit position.

Just to avoid confusion, the one in this case is negative and the zero is positive!

If the last bit of the signal was zero, we would need some way to distinguish the end of the symbol. This is a _stop bit_ and the options are one or two.

The final option for a symbol is whether to put a parity check on it. The parity characteristic can be;

- Even, the last data bit transmitted will be a logical 1 if the data transmitted had an even amount of 0 bits 
- Odd, the last data bit transmitted will be a logical 1 if the data transmitted had an odd amount of 0 bits 
- Mark, the last transmitted data bit will always be a logical 1
- Space, the last transmitted data bit will always be a logical 0
- None, no parity bit is transmitted 


## Default Settings
Most RS232 ports of communications equipment are marked “9600-8-N-1” which means 9600 bits/second, 8 bits, no parity, one stop bit.

Equipment I have commissioned since 2020 has a default bit-rate of 115,200 bits/second.

## Voltage Levels
RS-232 uses _bipolar voltage levels_. 

- A positive voltage (+3VDC to +15VDC) for a logic zero
- A negative voltage (-3VDC to -15VDC) for a logic one

Most electronics uses TTL levels where 

- 0V = logic zero
- 5VDC = logic one

Some electronics uses 3.3VDC as the high voltage!
Mixing these systems will result in permanent damage to the electroics.
We need to use level shifter adapters to convert from one to the other.
