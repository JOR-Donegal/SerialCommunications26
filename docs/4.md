# RS422 and 485

In previous notes, we saw that despite the simplicity and ubiquity of RS232. It does have some major drawbacks.

- Its range is limited
- Its bandwidth is limited and related to range 
- It is point to point, one duplex connection per link. 

Other physical protocols have been developed to eliminate these issues and are commonly used in industrial communications. In data centers, we will find them in the automation of Power and Heating, Ventilation and Cooling/Air Conditioning (HVAC). 

For example, _RS422_ can transmit to up to 10 receivers and can communicate at up to 10 Mb/s. It uses balanced, differential communications which provides much better noise immunity than RS232. RS422 can be used for long range point-to-point links, as a replacement for RS232. It should also be used where a single MASTER device will transmit data to (up to) ten SLAVE devices. If you examine a boat which is wired for traditional electronic instruments, you will see the use of a communications standard NMEA0183 and the physical standard RS422.

RS422 should not be used where bi-directional data is required between multiple devices; we use _RS485_ for this functionality. Process control systems have used this protocol for many years.  

Up to thirty-two RS485 transceivers can occupy a single bus and can communicate at up to 10 Mb/s. It uses balanced, differential communications which provides much better noise immunity than RS232. RS485 is used where multiple transceivers must communicate and each transceiver is part of a multi-drop network. Devices are daisy-chained together, and each device has a unique address. It can also be used in 4 wire mode, where a master device driver can connect to the receivers of all slave devices and the slave drivers are connected to the master receiver. 

RS485 is used as the basis for many industrial data communications systems, including PROFIBUS. MODBUS based systems are also commonly implemented using RS485. Look up CANBUS, this is used in industry and in automotive vehicles.

Where an RS485 bus is greater than 1200m long, repeaters may be used to extend the bus.

I'm not gong to cover it here, but another option for long range communications is to use a _4-20mA current loop_.

## Balanced v. Unbalanced
In RS232, each signal appears on a single line with reference to a signal ground. When noise is picked up on a single signal line, it also shows with respect to ground. Once the noise level exceeds +/-3V, it may appear as a bit and errors will occur. This is an _unbalanced signal line_ and although it has the advantage of simplicity, it is very limited in its usage.

With _balanced signals_, two signal lines are dedicated per signal (A and B) and these lines carry opposite signals. When A is negative with respect to B, this is a binary one. When A is positive with respect to B, that is a binary zero.

When noise occurs, it shows with the same polarity on each line and can be cancelled. The signal shows as a differential value between the two signal lines and is much easier to detect.
