    Experimentation

    The Raspberry PI (RPi) is a very handy tool for experimenting with serial communications, I use a range of interface HATS to do development work with serial protocols.

    RS232 is built-in, one usable port on early board. Although there are 6 serial ports on a RPi 4, they are frustratingly difficult to use as they overlap with other functions.

    The other protocols mentioned in this paper require some special boards.

    In the photograph (Fig 10), the board on the left is a high-quality serial board, which I use for RS422 marine telemetry and NMEA0183. One version of that board supports the more modern CANBUS-like standard NMEA2000.

    The board on the right is an inexpensive RS485 interface.

    Virtualised Experimentation

    I do not want you to test this, there is only so much we can pack into any module!

    When I'm doing experimentation work, I can do so in a virtualized environment. If I'm working on a domain specific language (DSL) used for encoding information, I will first set up a simple Linux VM to generate the DSL, a simulator. Using a technology like VMware workstation, I can configure serial links between two devices. On the second VM, I can then create a parser for the DSL. It sounds complicated, but this is a standard methodology.

    To start, I install pyserial.

    pip install pyserial

    I asked ChatGPT to generate a simple serial chat program for me. it uses multithreading so that send and recieve can happen simultaneously.

    import serial
import threading


# Set the corrent port device!
PORT = "/dev/ttyS0" 
BAUDRATE = 9600

ser = serial.Serial(PORT, BAUDRATE, timeout=1)

def receive():
    # Continuously read incoming messages
    while True:
        try:
            data = ser.readline().decode("utf-8").strip()
            if data:
                print(f"\nPeer: {data}")
        except Exception:
            break

# Start receiver thread
threading.Thread(target=receive, daemon=True).start()

print("Serial chat started. Type messages and press Enter.\n")

# Main send loop
while True:
    try:
        msg = input("You: ")
        ser.write((msg + "\n").encode("utf-8"))
    except KeyboardInterrupt:
        print("\nExiting chat.")
        break

ser.close()

    Once the source and parser appear to be working, they are saved to a git repo and then I can comfortably copy them down to physical hardware for the next stage of testing using a git clone. Up to now, I have only tested this as a simulator. At this point I begin hooking up to a reference source, a piece of real equipment to test against.
